# Chai Tower ☕

A small physics stacking game. Tap to drop kulhads, samosas, biscuits and one very heavy kettle, and stack the chai stall as high as you can. Everyone gets the same item order each day.

**Play:** https://heeray1.github.io/chai-tower/

- Plain HTML5 + [Matter.js](https://brm.io/matter-js/) (MIT), no build step. Open `index.html` through any static server.
- `?bot=3` auto-plays (useful for testing and recording footage).
- `art/gen.py` regenerates the art assets with a local image model.
